## English Version

AGI is an interactive Artificial Intelligence ecosystem with a native local architecture designed for public and private institutions. The project ensures technological independence and pedagogical accessibility without relying on cloud connectivity or extractive commercial licensing.

### Core Pillars
* **Zero Telemetry (Absolute Privacy):** The system operates in a 100% on-premise environment, ensuring that no sensitive information is exfiltrated to third-party servers.
* **Hardware Optimization:** Smart resource allocation (RAM/VRAM) allows quantized language models to run on existing institutional hardware, regardless of equipment specifications.
* **Technological Sovereignty:** Eliminates the need for expensive cloud-based (SaaS) licenses, converting institutions into self-sufficient technological environments.

### Technical Architecture
The system provides high performance and low latency through a specialized native stack:
* **Core:** Developed in **C#** using asynchronous programming for efficient sub-process management.
* **Inference:** **llama.cpp** for high-efficiency local execution of quantized LLMs.
* **Graphic Engine:** **Godot Engine** for the 3D interactive avatar and user interface.
* **Speech-to-Text (STT):** **Whisper** for robust, multi-language speech recognition.
* **Text-to-Speech (TTS):** **Sherpa-ONNX (C++)** integration, supporting high-quality **Kokoro** and **VITS** models for natural voice interaction.

## Versión en Español

AGI es un ecosistema de Inteligencia Artificial interactivo de arquitectura local nativa diseñado para instituciones públicas y privadas. El proyecto garantiza la independencia tecnológica y la accesibilidad pedagógica sin depender de conectividad a la nube ni de licenciamientos comerciales extractivos.

### Pilares Centrales
* **Zero Telemetry (Privacidad Absoluta):** El sistema opera en un entorno 100% local (on-premise), garantizando que la información sensible jamás sea exfiltrada a servidores de terceros.
* **Optimización de Hardware:** Sistema de asignación inteligente de recursos (RAM/VRAM) para ejecutar modelos de lenguaje cuantizados en el hardware existente, independientemente de la gama del equipo.
* **Soberanía Tecnológica:** Elimina la necesidad de licenciamientos costosos en la nube (SaaS), convirtiendo a las instituciones en entornos tecnológicos autosuficientes.

### Arquitectura Técnica
El ecosistema ofrece alto rendimiento y baja latencia mediante un stack especializado:
* **Núcleo Nativo:** Desarrollado en **C#** utilizando programación asíncrona para gestionar subprocesos de forma eficiente.
* **Inferencia:** **llama.cpp** para la ejecución local de modelos de lenguaje cuantizados.
* **Motor Gráfico:** **Godot Engine** para la integración del avatar interactivo 3D y la interfaz de usuario.
* **Reconocimiento de Voz (STT):** **Whisper** para un procesamiento de voz a texto robusto y multilingüe.
* **Síntesis de Voz (TTS):** Integración con **Sherpa-ONNX (C++)**, con soporte para modelos de alta fidelidad **Kokoro** y **VITS**.

## Implementation / Implementación

The AGI ecosystem is currently being validated and implemented at the **Escuela Preparatoria No. 17 (University of Guadalajara)**.
El ecosistema AGI está siendo validado e implementado actualmente en la **Escuela Preparatoria No. 17 (Universidad de Guadalajara)**.

* **For Students:** Provides a 24/7 academic tutor that respects privacy and functions without internet access.
* **For Teachers:** Tool for structuring classes and analyzing complex texts without compromising data security.
* **Impact:** Positions the institution as a leader in technological innovation and digital sovereignty in Jalisco.
